# Gemini Assistant Instructions (GEMINI.md)

Project: **Faruk Stock Metadata Generator Pro**
Framework: Express.js (Node 20+) + Vite 6 + React 19 + TypeScript + Tailwind CSS v4.

## How to Build and Run
- Install dependencies: `npm install`
- Dev server: `npm run dev`
- Production build: `npm run build`
- Start server: `npm start`
- Typecheck & Lint: `npm run lint`

## Permanent Feature & SEO Directives
- **Zero-Trademark Policy**: Reject all brand trademarks (BOSU, CrossFit, Zumba, Apple, Nike, etc.) and convert to safe generic terms (`half balance ball`, `dance fitness`, `functional fitness`, `smartphone`, etc.).
- **Title Punctuation**: Always end stock titles with a single full stop (`.`).
- **Keyword Alignment**: First 10 keywords must match title vocabulary in priority order.
- **Single Port Server**: Dev server and backend API run on port 3000 via `server.ts`.
